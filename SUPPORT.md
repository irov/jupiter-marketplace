# Jupiter Support

Use the [public issue tracker](https://github.com/irov/jupiter-marketplace/issues) for reproducible bugs and feature requests.

Before reporting a problem:

1. Run **Jupiter: Run Diagnostics**.
2. Open **Jupiter: Show Logs** and find the first relevant warning or error.
3. Confirm the installed Jupiter version and run **Developer: Reload Window** after an update.
4. Check whether the capability is `Needs configuration` in the Control Center.

Include the operating system, VS Code version, Jupiter version, the first relevant diagnostic, and minimal reproduction steps. Never include provider tokens, connection strings, repository content, private task text, or other secrets.
